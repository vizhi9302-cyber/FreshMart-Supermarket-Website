# FreshMart – Supermarket E-Commerce Website

A full-stack supermarket e-commerce website developed using HTML, CSS, JavaScript, Node.js, Express.js and MySQL.

## Features

- 🛒 Product browsing
- 🔍 Product search
- 🛍️ Add to cart
- ❤️ Wishlist
- 💳 Checkout
- 📦 Online order placement
- 👨‍💼 Admin login
- ➕ Admin product management
- 📋 Customer order management
- 🔄 Order status update
- 📱 Mobile responsive design
- 🗄️ MySQL database integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- XAMPP

## Project Structure

- Frontend pages
- Admin panel
- Node.js backend
- MySQL database
